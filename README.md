# 慢慢显影 · 六周年

一个纯白背景、以 Mini 7 拍立得为主角的纪念网站。第一版含 21 张演示风景照片，按固定顺序出片。点击相机拍照；显影后点击照片翻面；收好后可以点击照片堆回看。全部拍完后显示结束语。

手机、平板和电脑使用同一页面。演示进度仅保存于当前浏览器，不在设备间同步。默认静音，拍过第一张后可开声音。浏览器要求减少动态效果时直接完成动作。

## 本地预览

在此目录执行 `npm start`，打开 http://localhost:4173。没有构建步骤，也没有安装依赖的需要。

## 替换内容

编辑 `dist/memories.js`。数组顺序就是拍摄顺序，每项的 `image`、`title`、`text` 分别对应照片、白边标题和背面文字。图片放入 `dist/assets/` 并使用相对路径。推荐照片主体放在中间，图片区域按 46:62 裁切。

目前条目均为演示素材，没有编造真实日期或共同经历。要改成 20 张，删去数组中的一项；界面的计数自动跟随。正式替换时同时更新 `app.js` 的 STORAGE_KEY，避免演示进度带入正式版。首页不放标题或导航，只有相机；后续轻量提示在第一次拍摄后出现。

## 素材与参考

- 相机由内置 ImageGen 根据用户提供的实物图片生成，素材保留透明背景，最终提示词见 `camera-prompt.txt`。生成图是视觉近似素材，并非真实产品照片。
- 21 张演示照片来自 Lorem Picsum / Unsplash。逐张摄影师和原始来源见 `photo-sources.json`；照片只作为排版演示。
- 产品结构参考 [富士 instax mini 7S 官方说明书](https://instax.com/support/pdf/instaxmini7s_manual_01.pdf)。模型名称继续沿用用户的 Mini 7 称呼。
- 动效使用 Feel MIT runtime。`dist/motion-lab.html` 是独立的开发校验台，不在访客页面中显示。

## 发布

站点身份和静态目录位于 `.openai/hosting.json`，通过 Sites 源码与版本发布流程部署。初始访问权限为仅站点拥有者；此版本尚未开放给其他访客。
