# 慢慢显影 · 六周年

一个白色背景、以 Mini 7 拍立得为主角的纪念网站。现含 21 张演示照片，按数组顺序出片。

点击相机或快门按钮，相纸会从顶部开口送出，逐渐显影，然后自动飞到页面上方的晾绳，用木色夹子挂好。鼠标经过时会绕夹子轻摆并自然停下。点击绳上的照片可以放大、翻面、前后查看，再挂回原处。顶部“已经显影”可打开完整相册。照片变多时，晾绳可左右滚动，手机支持原生横向触摸浏览。

手机和电脑用同一页面。演示进度保留于当前浏览器；本次更新沿用原进度键，旧版本拍过的照片会直接挂到绳上。默认静音。减少动态效果的系统设置会取消出片等待、飞行和摆动。

## 本地预览

此目录执行 `npm start`，打开 http://localhost:4173。无需构建或安装依赖。

## 替换内容

编辑 `dist/memories.js`。数组顺序是拍摄顺序。每项 `image`、`title`、`text` 对应照片、白边标题、背面文字。图片放入 `dist/assets/`。图片按 46:62 裁切，相纸整体保持 54:86。减至 20 张时，删除数组中的一项即可，页面计数随之调整。正式替换内容时同步更新 `app.js` 的 STORAGE_KEY，避免携带演示进度。

照片和背面文字都是明确的演示，没有添加虚构的真实日期或共同经历。

## 相机与出纸口

相机由内置 ImageGen 根据用户实物图生成，保留透明壳、淡紫色快门和奶牛纹背带，原始资产与提示词见 `camera-prompt.txt`。页面使用与 PNG 像素完全相同的无损 WebP，原 PNG 仍保留。

`geometry.js` 根据 1316 x 1195 素材记录出纸口坐标，统一计算纸张宽度、底边和方形容器的留白。纸张在机身后沿前方、前沿后方，夹在两个相机图层之间。更换相机素材时需要重新校准坐标与前沿遮罩。

## 参考与素材

- 设计和动效参考 [Tendedero](https://github.com/alejandrobujan/tendedero) 的顶部悬挂与摆动思路，未移植 Swift 源码；没有使用它的玻璃相框、金属夹、名称或图标。
- 21 张演示照片来自 Lorem Picsum / Unsplash。摄影师及来源见 `photo-sources.json`。
- 产品结构参考 [富士 Mini 7S 官方说明书](https://instax.com/support/pdf/instaxmini7s_manual_01.pdf)。相机仍是生成的视觉近似，不是真实产品照片。
- Feel MIT runtime 负责物理轨迹，转交浏览器播放的关键帧时长由模型收敛计算。用户界面无持续循环的漂浮效果。
- `alignment-lab.html` 与 `motion-lab.html` 是未在主页面链接的制作校验页。设计审查见 `design-notes.md`。

## 验证与发布

`node qa-flow.cjs` 验证 21 张顺序自动挂起、翻面、归位、边界、最后一张、重置、旧进度恢复、减少动效、图片失败重试和若干尺寸的出纸口几何关系。它使用 DOM 替身与真实物理求解器，不能代替浏览器视觉检查。截图及当前验证范围位于 `qa/`。

`.openai/hosting.json` 保留同一站点身份，通过 Sites 源码及版本流程发布，访问权限沿用现有设置。
